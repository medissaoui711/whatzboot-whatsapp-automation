## 2. Color Palette

The color palette is minimal and professional, built around the core WhatsApp green to create a sense of trust and familiarity.

| Color               | Hex       | Usage                                       |
|---------------------|-----------|---------------------------------------------|
| **Primary**         | `#16A34A` | Main calls-to-action, active states, accents. |
| **Secondary**       | `#FFFFFF` | Main background color, text on dark backgrounds. |
| **Accent**          | `#F3F4F6` | Secondary backgrounds, dividers.            |
| **Notification**    | `#3B82F6` | Informational alerts, notifications, links.   |
| **Text (Dark)**     | `#111827` | Primary text color on light backgrounds.    |
| **Text (Light)**    | `#374151` | Secondary text, placeholders, subtitles.    |

---

## 3. Typography

The typography is chosen for its clarity, readability, and modern feel across both English and Arabic languages.

### Headings
- **Font:** Inter Bold (or Poppins Bold)
- **Usage:** Main titles, section headers, and important text.

### Body Text
- **Font:** Inter Regular (or Open Sans)
- **Usage:** Paragraphs, descriptions, and standard text.

### Arabic Support
- **Font:** Tajawal (or Cairo)
- **Usage:** Use for all UI elements when the language is set to Arabic.

---

## 4. Iconography

Icons should be simple, consistent, and clear.

- **Library:** Use icons from **Lucide Icons** or **Heroicons**.
- **Style:** Linear, minimalist, and monochrome.
- **Color:** Icons should be colored using either the Primary (`#16A34A`) or Text (`#111827` / `#374151`) colors.

---

## 5. Design System (UI Components)

Consistency in UI elements is key to a professional user experience.

- **Rounded Corners:** Use a border-radius of **8px** for primary containers like cards and buttons.
- **Shadows:** Apply subtle shadows (`shadow-sm`) to create depth for interactive elements or cards.
- **Spacing:** Use a consistent spacing scale based on multiples of 4px (e.g., `16px`, `24px`, `32px`) for margins and padding.
- **Contrast:** Ensure all text has a high contrast ratio against its background to meet accessibility standards (WCAG AA).
